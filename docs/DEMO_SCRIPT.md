# AI StudyMate Demo Script

## 발표 목표

짧은 시간 안에 다음 메시지를 전달합니다.

> AI StudyMate는 강의 전사 텍스트와 PDF 자료를 AI가 분석하여 요약, 질문, 문제 생성, 그리고 시험일까지의 학습 일정으로 연결하는 서비스입니다.

---

## 1. 발표 전 준비

- 발표용 PDF를 미리 준비합니다.
- PDF는 텍스트 선택이 가능한 1~5페이지 자료를 사용합니다.
- 발표용 질문을 미리 정합니다.
- 과목명과 시험일을 미리 확인합니다.
- `.env.local`의 Mock/OpenAI 모드를 확인합니다.
- OpenAI 실패에 대비해 Mock fallback을 준비합니다.
- 브라우저 창 크기와 확대율을 고정합니다.
- 개발 서버 또는 배포 URL을 미리 열어둡니다.

---

## 2. 발표 흐름

### 2.1 문제 설명 — 20초

발표 문구:

> 대학생은 강의자료, 필기, 시험일이 여러 곳에 흩어져 있어 긴 자료를 빠르게 이해하고 오늘 무엇을 공부할지 결정하기 어렵습니다.

### 2.2 서비스 소개 — 15초

발표 문구:

> AI StudyMate는 전사 텍스트와 PDF 자료를 입력받아 요약, 자료 기반 Q&A, 문제 생성, 그리고 시험일까지의 학습 계획을 제공합니다.

### 2.3 Today 화면 — 15초

보여줄 내용:

- 과목명
- 시험일
- D-Day
- 오늘의 학습 태스크

발표 문구:

> 앱을 열면 Today 화면에서 시험일까지 남은 기간과 오늘 해야 할 학습 내용을 먼저 확인할 수 있습니다.

### 2.4 PDF 업로드 — 25초

동작:

1. Materials 탭으로 이동합니다.
2. 발표용 PDF를 선택합니다.
3. 추출된 텍스트와 글자 수를 확인합니다.

발표 문구:

> 강의 전사 텍스트를 직접 붙여넣거나, PDF 자료를 업로드할 수 있습니다. PDF는 서버에서 텍스트로 추출됩니다.

### 2.5 AI Summary — 25초

동작:

1. Summary 버튼을 누릅니다.
2. 키워드, 핵심 개념, 쉬운 설명을 보여줍니다.

발표 문구:

> AI가 긴 강의자료를 핵심 키워드와 개념 중심으로 정리하고, 이해하기 쉬운 설명을 제공합니다.

### 2.6 자료 기반 Q&A — 20초

추천 질문 예시:

```text
이 자료에서 가장 중요한 개념은 무엇인가요?
```

또는 PDF 주제에 맞는 구체적인 질문을 사용합니다.

발표 문구:

> 질문 기능은 업로드한 자료를 함께 전달하기 때문에 자료 안의 내용을 기준으로 답변합니다.

### 2.7 Quiz — 15초

동작:

1. Quiz 탭으로 이동합니다.
2. 객관식 또는 OX 문제를 생성합니다.

발표 문구:

> 요약 내용을 문제로 다시 확인해 단순히 읽는 것에서 끝나지 않도록 했습니다.

### 2.8 Today Plan — 20초

동작:

1. Today로 이동합니다.
2. 현재 계획을 보여줍니다.
3. 가능하면 시험일을 변경해 계획 변화를 보여줍니다.

발표 문구:

> AI 결과를 보여주는 데서 끝나지 않고, 시험일까지 남은 기간에 맞는 오늘의 학습 계획으로 연결합니다.

### 2.9 마무리 — 15초

발표 문구:

> 이번 POC에서는 텍스트와 PDF 기반 흐름을 구현했습니다. 향후에는 음성 직접 녹음과 STT, DOCX, 사용자별 학습 기록, RAG로 확장할 계획입니다.

---

## 3. 시연 실패 대비

### PDF 업로드 실패

- 텍스트 붙여넣기 fallback을 사용합니다.

### OpenAI 호출 실패

- `USE_MOCK_API=true`로 전환합니다.
- Mock 결과로 동일한 화면 흐름을 보여줍니다.

### 인터넷 또는 배포 실패

- 로컬 개발 서버를 사용합니다.

### 특정 탭 오류

- 오류가 난 탭은 건너뛰고 핵심 흐름을 이어갑니다.
- Summary와 Today Plan을 우선 보여줍니다.

## 4. 예상 질문과 답변

### 왜 음성 파일을 직접 업로드하지 않았나요?

> 이번 POC에서는 외부 도구에서 변환한 전사 텍스트와 PDF 분석에 집중했습니다. 음성 직접 녹음과 STT는 다음 단계로 계획하고 있습니다.

### 기존 ChatGPT와 어떤 차이가 있나요?

> 일반 챗봇은 사용자가 질문해야 답하지만, AI StudyMate는 자료 분석 결과를 시험일까지의 Today Plan으로 연결해 다음 행동을 먼저 제안합니다.

### 자료 밖 질문은 어떻게 처리하나요?

> 자료 범위를 벗어난 질문에는 자료에 없다는 응답을 반환하도록 설계했습니다.

### OpenAI API 장애가 나면 어떻게 하나요?

> 발표와 개발 안정성을 위해 Mock 모드를 준비했고, 환경변수로 실제 AI와 Mock을 전환할 수 있습니다.

### 개인정보나 API 키는 안전한가요?

> API 키는 서버 환경변수에만 저장하며 클라이언트에 노출하지 않습니다. 이번 POC는 로그인과 개인 데이터 서버 저장 기능을 포함하지 않습니다.
