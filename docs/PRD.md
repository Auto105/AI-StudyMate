# AI-StudyMate POC PRD

## 제품 정의

AI-StudyMate는 “오늘 무엇을 공부해야 할지 먼저 알려주는 AI 학습 도우미”입니다. POC의 중심 화면은 `Today`이며, 요약·Q&A·plan은 사용자의 다음 행동을 정하기 위한 보조 엔진입니다.

## 원본 로드맵 기준

원본 요구사항 문서는 `docs/ai-studymate-roadmap.md`입니다.

## 필수 Phase 순서

필수 순서는 다음으로 고정합니다.

```text
P0 → P1 → P2 → P4 → P5
```

`P3 Quiz`는 보너스입니다. P4와 P5 이후 시간이 남을 때만 다루며, Today 화면의 필수 동선에 넣지 않습니다.

## 핵심 사용자 흐름

1. 사용자가 앱을 열면 `오늘` 탭이 먼저 보입니다.
2. 과목명과 시험일을 확인합니다.
3. D-day 배지와 오늘 할 일 2~3개를 확인합니다.
4. 자료를 추가하고 요약할 수 있습니다.
5. 사용자는 추가한 자료 범위 안에서 질문할 수 있습니다.
6. 시험 문제 생성은 별도 `시험` 탭에서 보너스로 제공합니다.

## Today 화면 IN/OUT

### 포함

- 과목명
- 시험일
- D-day 배지
- 오늘 할 일 2~3개
- `오늘 공부 시작하기` CTA
- D-5와 D-2에서 달라지는 오늘 할 일

### 제외

- 진도율
- 학습량 %
- AI 점수
- 중요도 별점
- Today 필수 퀴즈 카드
- 완료율 자동 갱신 루프

## 자료 제한

- PDF 파일은 5MB 이하로 제한합니다.
- 추출 텍스트는 12,000자까지 사용합니다.
- 실제 PDF 파싱은 이번 작업에서 구현하지 않습니다.
- 텍스트 직접 붙여넣기 fallback은 유지합니다.

## API와 fallback 범위

- `summary`: Mock 요약을 반환합니다. 실제 OpenAI 연결은 후속 작업입니다.
- `chat`: 자료 안 질문만 답변합니다. 자료 밖 질문은 `자료에 없습니다`를 반환합니다.
- `plan`: D-5와 D-2에서 서로 다른 오늘 할 일을 반환하는 Mock 구조를 둡니다.
- `quiz`: 보너스 기능이며 Mock 문제만 반환합니다.

로드맵에는 `cache/summarize.json`, `cache/quiz.json`, `cache/plan.json` fallback이 포함되어 있지만, 이번 작업에서는 실제 캐시 파일과 캐시 로직을 구현하지 않습니다.

## 이번 구현 범위

- Next.js App Router 기반 기본 구조
- 4개 탭 UI 골격
- Mock API Route 5개
- 공통 타입과 Mock 데이터
- localStorage 기반 과목/시험일/자료/요약/Today plan 저장
- 협업 문서
